# Piano 🎹

Este es un piano simple hecho con HTML, CSS y JavaScript.

## Funciones

- Tiene notas de DO a SI
- Genera sonido usando JavaScript
- Funciona desde el navegador
- Se puede usar desde celular

## Tecnologías usadas

- HTML
- CSS
- JavaScript

## Cómo usarlo

1. Abrir el archivo `Piano.html`
2. Tocar una de las teclas
3. Cada botón reproduce una nota
